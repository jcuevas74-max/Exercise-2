# Wine Quality Prediction System — Complete Project

**Technology:** Python, Pandas, Scikit-learn, Random Forest, Streamlit

## Included Files
- `train_model.py` — downloads data, trains model, and prints evaluation metrics
- `app.py` — Streamlit app for single-sample and batch predictions
- `requirements.txt` — dependencies
- `SAD_Mini_Analysis.md` — SAD mini-analysis
- `Reflection_Answers.md` — answers to all five reflection questions
- `Dataset_Information.md` — dataset source, features, and target rule

## How to Run
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Open Terminal in the project folder.
4. Install packages: `pip install -r requirements.txt`
5. Train model: `python train_model.py`
6. Start app: `streamlit run app.py`
7. Open `http://localhost:8501`.

Run `train_model.py` first. It downloads `wine_quality.csv` and creates `wine_model.pkl`.

## Model
Random Forest (150 estimators, random state 42, balanced class weights), 80/20 stratified train-test split, median imputation, and StandardScaler. Evaluation includes accuracy, confusion matrix, and classification report. Actual metric values appear after running training; they are not prefilled.

## Classification
- Quality >= 6 → GOOD QUALITY
- Quality < 6 → NEEDS IMPROVEMENT
Quality is target-only and is not an input feature.

## Important Limitation
This is a classroom prototype and preliminary screening tool. It does not replace laboratory testing, sensory evaluation, food-safety procedures, or professional quality-control decisions. It may not generalize to other producers or conditions.
